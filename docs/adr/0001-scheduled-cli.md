# ADR 0001：单次 CLI、launchd 与标准库优先

- 日期：2026-11-01
- 状态：设计已采纳，未实现

## 背景

单台 Mac mini 每天处理一台摄像机的历史事件；用户优先考虑低资源消耗和维护成本，不需要持续接收实时画面。

## 决策

使用 Python 3.12+ CLI，由用户级 launchd 每日启动，完成退出。协调逻辑、TOML、SQLite、HTTP 与文件锁优先标准库；平台凭据采用 macOS Keychain。FFmpeg/ffprobe 处理媒体，独立 aliyunpan CLI 负责上传。单片串行、默认流复制，暂不打包第三方二进制。

## 替代方案

常驻 Web 服务或 Docker 增加持续开销和部署依赖，当前不采用。Swift 原生应用可减少解释器依赖，但现阶段协议适配和能力探测变化较多，先用 CLI 缩短验证路径。cron 的用户会话和环境维护体验不如目标平台的 launchd，此阶段不采用。

## 代价与验证

Python 和外部二进制仍有安装与版本管理成本；标准库优先不等于无需实现超时、流控和安全凭据适配。LaunchAgent 依赖登录会话，不能保证未登录或休眠期间执行。资源目标必须在真实 Mac 测量；如第三方工具超出预算，调整适配器或目标并公开记录。
