# ADR 0003：增量归档、独立核验与保守清理

- 日期：2026-11-01
- 状态：设计已采纳，未实现

## 背景

SD 卡会循环覆盖，网络和网盘授权可能中断。单凭上传进程退出成功不足以证明远端存在完整备份；删除策略错误可能同时丢失本地和云端副本。

## 决策

SQLite 保存稳定事件键、确定性片段路径及逐步状态。上传后独立查询远端元数据；精确大小匹配记为 size，大小及 SHA-1 一致记为 sha1。无法查询元数据则保留 UPLOADED，不标为 VERIFIED。

只做增量归档，永不传播删除、不覆盖冲突文件。默认关闭本地清理；未来显式开启还需要 sha1 核验及保留期。流式哈希、单片段串行处理，不默认整片回下载。

## 替代方案

双向同步或排他镜像会传播删除，当前不采用。上传成功立即删除会放大错误，当前不采用。全部回下载校验可获得额外证据但增加流量及耗时，初期不设为默认。

## 代价与验证

数据库和状态机需要迁移及崩溃恢复测试。工具是否能提供稳定远端元数据仍是实现门槛。size 等级不能证明内容完全相同，默认也不允许触发清理；保留原片会占满暂存空间并暂停，需要状态提示及用户管理，详见 [运维设计](../operations.md)。
