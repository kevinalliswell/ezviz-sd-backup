# 测试与验收计划

## 当前能验证的内容

本仓库处于设计阶段。执行以下检查，不需要摄像机、网盘账号或第三方 Python 包：

```sh
python3 scripts/check_repo.py
git diff --check
```

检查范围是必需文件、本地 Markdown 文件链接、配置契约及安全默认值、launchd 模板。不验证第三方链接在线状态、全部 Markdown 语法、真实设备能力、资源指标或备份正确性。GitHub Actions 运行同一静态检查。

## 第一阶段：真实设备能力门槛

在目标 Mac 的用户会话内执行，凭据和测试录像仅保存在本机私有目录。环境记录至少包含 C6C 完整型号、固件、Mac 架构、macOS、Python、FFmpeg 与 aliyunpan 版本及来源；设备序列号不公开。

1. 在萤石 App 找到一个 SD 卡中仍存在的已知告警事件，记录日期及时区。
2. 用合法开放平台授权检索该日事件，对照 App 中的时间，验证完整分页及录像来源。
3. 获取这个历史时段的回放，保存指定的 60 秒；保持现有设备加密设置，不能用直播作为替代。
4. 用 ffprobe 检查流、编码、时间与大小，人工核对首尾画面、音频及历史时间；设备未录音时记录预期无音频。
5. 记录实际耗时、CPU、内存及服务费用/额度条件。标准流无法使用时记录错误与能力缺口，暂不实现每日备份链路。

## 第二阶段：实现后的离线测试

不保存真实 API 响应为 fixture，使用最小合成响应。测试行为和故障边界，避免只断言实现细节。

| 范围 | 代表性用例 |
| --- | --- |
| 时间与分页 | 秒/毫秒转换、跨午夜、月底/年底、时区夏令时边界、重复页、游标不前进、分页中途失败 |
| 事件语义 | 事件与定时录像分开、空列表与错误分开、长事件完整分段、重复发现不增加任务 |
| 媒体保存 | 错误页返回 HTTP 200、提前断流、FFmpeg 提前退出、阻塞写入、超时、不可用编码 |
| 状态恢复 | 下载/上传中断、rename 后提交前崩溃、本地文件丢失或被改动、SQLite 迁移失败 |
| 云端校验 | 上传退出成功但远端缺失、大小不符、哈希缺失/不同、同名冲突、元数据延迟 |
| 调度与预算 | 第二实例安全跳过、运行预算耗尽、空间临界、单片失败不饿死其他待办 |
| 清理保护 | 默认不清理、size 等级不可清理、保留期未满、失败/冲突/未核验永不删除 |
| 凭据与日志 | 含令牌的错误响应先脱敏；argv、plist、日志、异常栈无密钥及签名 URL |

网络及子进程边界应可替换，CI 不需要真实账号，也不以在线视频样本或家庭录像为依赖。

## 第三阶段：Mac 端到端与调度

| 验收项 | 通过标准 |
| --- | --- |
| 一天的真实事件 | 与 App 对照事件索引，全部片段落盘、上传并独立核验；缺口明确记录 |
| 重复运行 | 同一路径不增加副本，不重复下载已完成且有效的原片 |
| 两类中断 | 下载、上传各中断一次，重跑能恢复且不误报成功 |
| 非交互授权 | 手动终端和 launchd 会话均可读取所需凭据；锁屏时单独测试 |
| 三天定时运行 | 每次03:15附近启动、摘要及退出码可查、完成后无应用残留进程 |
| 生命周期 | 测试休眠唤醒、重启未登录及登录后行为，记录实际限制 |
| 网盘核验 | 独立取得对象精确大小；有 SHA-1 则验证，缺失则如实记为 size 等级 |
| 预算与保留 | 模拟低磁盘及满暂存，暂停且不删原片；清理保持默认关闭 |

如果独立元数据核验路径尚未实现，不能把端到端验收标记通过。仅 size 核验可如实用于备份状态，但不满足默认本地清理条件。

## 资源测量

设计目标尚未实测：协调器峰值 RSS ≤80 MiB；同一时刻所有任务相关进程 RSS 合计峰值 ≤300 MiB；未运行时应用常驻进程为 0。合计 RSS 是保守指标，需明确共享页可能重复计数。

在实际一次任务中每秒采样协调器、FFmpeg/ffprobe、aliyunpan 及其子进程的 PID/PPID、RSS、CPU 使用率；macOS `ps` 的 RSS 以 KiB 报告。不能将各进程在不同时刻的各自峰值简单相加作为同一时刻峰值。采样工具只在测试期间运行，结果存仓库外。

同时记录片段数量、录像总时长、总耗时、下载/上传耗时、峰值暂存、网络流量及主机型号。CPU/能耗先给实测记录，再决定是否需要额外限速；不发布未经测量的低功耗百分比。

验收后公开的测试结论仅包括脱敏环境、版本、通过项、限制及资源统计。保留原始证据在本机，不能上传录像、数据库、凭据或含设备信息的截图。
