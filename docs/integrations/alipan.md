# 阿里云盘接入

## 工具选择

MVP 计划封装 [tickstep/aliyunpan](https://github.com/tickstep/aliyunpan) 的命令行上传能力。它是第三方开源工具，项目说明包含 macOS Intel / Apple Silicon、上传及增量备份支持。

资料核对日期：2026-11-01。当前尚未在目标 Mac 上安装、授权或上传；实现时固定一个真实测试过的版本，记录二进制来源、版本与许可证，不使用自动追随最新版本的假设。

不要把阿里云 OSS 当作阿里云盘，也不要假设通用网盘工具或 WebDAV 自带对阿里云盘的官方支持。

## 用户授权与配置

首次登录由用户在自己的 Mac 上按工具当时的说明完成。该工具可能需要浏览器授权、扫码或再次授权，用户需了解第三方应用的访问范围；本项目不收集账号密码，不内置开发者私人凭据。

通过 `ALIYUNPAN_CONFIG_DIR` 将工具的凭据目录显式指向用户 Library 下，目录权限设为 `0700`、凭据文件尽可能为 `0600`。第三方工具可能以自己的配置格式持久化刷新令牌；不能因为本应用使用 Keychain，就声称所有第三方凭据也自动存入 Keychain。

验证首次授权后能否在非交互的 launchd 会话中使用。授权过期需要用户处理时，返回明确状态；不尝试自动点击登录界面。

## 单次上传适配器

适配器应提供以下内部契约，具体 CLI 参数和输出格式在实现阶段按固定版本验证，不在此编造命令参数：

```text
upload(local_path, remote_directory) -> UploadResult
stat(remote_path) -> RemoteMetadata(exists, size_bytes, content_hash?, hash_algorithm?)
```

- 用 `subprocess` 参数列表执行，设置专用配置目录和超时，不拼 shell。
- 显式将上传并发限制为 1；第三方程序自身的分片并发也需核实，不能只限制外层进程数量。
- 不运行无限循环的同步守护进程，任务完成后退出。
- 解析经固定版本验证的结果；不能只根据中文“成功”字样或进程退出码判定远端完整性。
- 上传后由独立 `stat` 路径检查远端对象；若工具没有稳定可解析的元数据输出，记录能力缺口并保持 `UPLOADED`，再评审官方 API 等替代方式。

## 校验等级

| 等级 | 条件 | 默认能否触发本地清理 |
| --- | --- | --- |
| 未核验 | 只有上传返回成功，或远端元数据不可用 | 否 |
| `size` | 远端路径存在，精确字节数与本地相同 | 否 |
| `sha1` | 远端路径、大小及 SHA-1 均与本地一致 | 仅在用户显式开启本地清理后允许 |

远端字段若使用其他哈希算法，只能在本地计算相同算法后比较，不能比较不同算法的摘要。远端哈希不可用时，不自动整片回下载，也不把大小匹配提升为哈希匹配。

## 远端目录与冲突

```text
/家庭监控/客厅/2026-11-01/14-32-10_a1b2c3d4e5f6.mp4
```

远端目录前缀可配置。相同稳定事件键复用同一路径；已存在且核验一致的文件复用，不产生副本。相同路径但大小或哈希不同则标记冲突并保留本地文件，不能自动覆盖或删除旧备份。

本项目仅做增量归档，永远不传播本地删除到云端。如果未来使用工具的同步功能，只能选择经验证的增量策略，禁止镜像/排他删除策略。项目不管理云端自动过期。

## 待实测事项

- 固定版本的非交互授权续期、上传退出码和错误格式。
- 精确字节数及内容哈希是否能可靠查询。
- 文件已存在时的行为、重复任务和冲突行为。
- 上传中断后的部分对象、断点处理与再次上传语义。
- 网盘空间不足、限流和账号失效时的可恢复错误分类。
- 上传分片并发及峰值内存是否满足项目目标。

工具说明中的会员或三方权益条件不能直接套用为上传必须条件，实际速度、额度与服务政策需按当前账号验证。
