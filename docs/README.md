# 文档导航

## 项目背景

用户已有一台萤石 C6C，仅使用 SD 卡保存录像，希望利用全天在线的 Mac mini，每天将已有告警片段备份到阿里云盘。本阶段交付可评审的设计、示例和开源仓库基础，后续在用户的 Mac 上验证并实现。
