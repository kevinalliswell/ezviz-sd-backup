# 下一阶段开发启动提示词

下面可直接交给 Codex 或 Claude Code，在已有仓库中启动下一阶段开发。它要求先做最小能力探测，不预设 C6C 已兼容。

```text
你正在开发 ezviz-sd-backup。目标设备是萤石 C6C，仅 SD 卡存储；运行主机是全天在线的 Mac mini；目标是每天将已有历史告警片段备份至阿里云盘。

先阅读 AGENTS.md、docs/requirements.md、docs/architecture.md、docs/integrations/ezviz.md、docs/integrations/alipan.md、docs/testing.md 与 examples/config.example.toml。保留用户现有改动。使用新分支，先检查 git status、当前分支和 upstream。

本次范围：P1 能力探测。不要一次性实现整个应用。

1. 先确认当前环境是否为目标 Mac，记录 Python/macOS/CPU 架构及 FFmpeg 版本。不是目标 Mac 时可以实现和测试离线逻辑，但不得宣称设备实测完成。
2. 重新查阅集成文档所列官方接口和固定版本 aliyunpan 说明。核对授权、时间单位、分页、事件类型及回放服务条件，不编造 CLI 参数。
3. 实现 Python 3.12+ 的最小项目结构和 probe 入口，标准库优先。实现配置校验、macOS Keychain 安全读取、HTTP 超时和脱敏错误。需要设置密钥时本地隐藏输入，通过安全平台接口写入 Keychain，不经进程参数或 shell 历史传递。
4. 先用合成响应覆盖秒/毫秒、分日分页、重复页、无进展游标、空结果/错误区别、授权失败和日志脱敏。真实配置、API 响应、录像、数据库、日志和密钥均在仓库外。
5. 在用户已具备合法设备授权的前提下，查询一个 App 中可核对的 SD 历史事件。能力不支持与无事件必须区分，不能把定时录像或直播当告警历史导出。
6. 用目标 Mac 保存指定历史时段的60秒。首选 HTTPS HTTP-FLV，Python 有界读取后送 FFmpeg stdin，签名 URL 不进入 argv。采用流复制，验证视频流、时长和首尾画面；不关闭设备加密、不更改摄像机绑定或设置。
7. 首次网盘授权由用户在自己的 Mac 完成；固定工具版本并核实单次上传、内部并发、精确远端大小/哈希查询能力。本阶段不上传家庭录像；只允许在后续用户授权测试中使用约定样本。
8. 缺少凭据或硬件时完成所有不依赖它们的实现及离线测试，再报告准确的待办。如果真实能力探测失败，记录安全的错误类别和证据，停止扩大实现范围，不改成直播、全天录像、VM或未经验证的SDK方案。

轻量约束：无常驻服务、无Docker、无Web UI、无AI推理、无默认转码；下载和上传并发都为1；有界I/O、子进程超时及终止；不把整个视频读入内存。不删除SD内容或云端备份，本地清理默认关闭。

同步维护文档和示例；运行 python3 scripts/check_repo.py 以及实现所需的有意义测试。需要新增依赖时说明必要性、许可证与资源成本。添加真实运行入口后更新当前“无应用实现”的状态声明，但仍保留未实测能力的准确标注。

验收输出：改动文件、运行及测试方法、离线测试结果、实机通过项/阻塞项、固定版本与资源实测、下一阶段最小任务。不要提交真实设备信息或录像；只有实际完成的工作可标为已实现或已验证。
```
